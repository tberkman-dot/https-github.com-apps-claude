# Weekly Budget Tracker — Claude.md

## Project Overview
This is a single-file web application that helps users track their weekly spending against a set budget. It runs entirely in the browser with no backend or installation required.

## What I Asked Claude to Build
I asked Claude Code to build an app that tracks your weekly budget. The app needed to:
- Let the user set a weekly spending limit
- Allow adding and deleting expenses
- Show how much has been spent vs. how much is left
- Break down spending by category
- Work without any login or server

## How Claude Helped
Claude (via Claude Code CLI) wrote the entire application as a single `index.html` file using HTML, CSS, and vanilla JavaScript. It designed the data model, the UI layout, and all the logic for week navigation, category tracking, and localStorage persistence.

I described what I wanted in plain English and Claude translated that into working code. I also asked follow-up questions about how to open and run the file.

## Technologies Used
- HTML5
- CSS3 (custom dark theme, responsive layout)
- Vanilla JavaScript (no frameworks)
- localStorage (for saving data in the browser)

## How to Run
1. Download `index.html`
2. Open it in any web browser (Chrome, Firefox, Safari, Edge)
3. No installation or internet connection needed after download
