# Project Description
## Weekly Budget Tracker

### What I Built

I built a weekly budget tracking web app using Claude Code (Anthropic's AI coding tool). The app is a single HTML file that runs entirely in the browser — no sign-up, no server, no installation required.

The app lets you:
- Set a weekly spending budget
- Log expenses by description, amount, and category
- See your remaining balance update in real time
- View a color-coded progress bar showing how close you are to your limit
- Browse a bar chart of your daily spending across the week
- See a breakdown of spending by category (Food, Transport, Shopping, Entertainment, Health, Utilities, Other)
- Filter transactions by day
- Navigate back to review previous weeks
- Delete any expense you entered by mistake

All data is saved automatically in the browser's localStorage, so your budget and expenses are still there when you close and reopen the page.

### How I Built It

I used **Claude Code**, an AI assistant made by Anthropic, to generate the code. I described what I wanted in plain English — a budget tracker app — and Claude wrote the full application in one file using HTML, CSS, and JavaScript. I asked follow-up questions to understand how to open and use the file, and the app worked immediately without any modifications needed.

### What I Learned

This project showed me how AI coding tools can turn a plain-language description into a working product very quickly. I learned that being specific about what you want (no login, no server, categories, persistence) leads to better results. I also learned the difference between running a file locally vs. on a remote server, which was a practical challenge I had to work through.
